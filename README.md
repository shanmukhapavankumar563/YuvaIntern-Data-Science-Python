# YuvaIntern Data Science with Python

This repository contains weekly projects for the YuvaIntern Virtual Data Science with Python Trainee internship. Each week has its own folder with code, setup instructions, and generated results where available.

## Getting started

Each project README lists its Python dependencies, dataset attribution, and execution command. Use a separate virtual environment per project, install that folder's `requirements.txt`, and run the documented script. Public datasets are downloaded and cached locally; raw data caches are excluded from Git. Reports and evaluation artifacts are generated by the scripts, so use the included outputs as recorded runs rather than guarantees of future results.

## Capstone

The Week 6 capstone demonstrates a complete acquisition-to-evaluation workflow with data-quality review, EDA, feature engineering, leakage-aware cross-validation, held-out testing, a Word report, and reproducible artifacts. See its README for source attribution, use conditions, limitations, and the complete task checklist.
